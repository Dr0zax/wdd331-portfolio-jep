Advanced text properties

text-wrap

Use balance for short headings and pretty for longer copy. Compare each value with normal greedy wrapping.

Live heading

A good headline gives every line room to breathe 

h3 {
  text-wrap: balance;
}

Best for short text: balancing is intentionally limited to a small number of lines.

initial-letter

A drop cap can now be declared instead of faked with a floated span. The number describes how many lines tall the first letter is.

Typography is the quiet structure behind a comfortable reading experience. A carefully sized first letter creates an editorial entrance without changing the meaning or markup of the paragraph. 

p::first-letter {
  initial-letter: 3;
}

Include -webkit-initial-letter as a Safari fallback and keep the paragraph readable without it.

ch and ex

ch approximates the width of a zero character, making it useful for readable line length. ex follows the x-height of the current font.

Good typography is invisible. When the measure is right, the reader's eye moves from the end of one line to the start of the next without effort or thought, and the words simply flow.

icon aligned to 1ex

65ch is in the comfortable 45–75 range. 

article p {
  max-width: 65ch;
}
.icon { height: 1ex; }

lh and rlh

lh is the current element’s computed line height. rlh uses the root line height, creating one shared rhythm across components.

One rhythm, many blocks

Each paragraph ends with 1lh of space. The heading starts after 2rlh, so the stack remains orderly as the root rhythm changes.

Try the slider: the spacing grows with the type instead of relying on a guessed pixel value. 

p { margin-block-end: 1lh; }
h2 { margin-block-start: 2rlh; }
