Let content choose its size.

Why does height: auto usually snap?

CSS can transition between two numeric lengths, but auto is calculated from the content. The browser has no numeric midpoint to use, unless we opt in to intrinsic-size interpolation.

Set interpolate-size: allow-keywords on the root or the component that needs it.

interpolate-size: allow-keywords

Default

This panel has the same fixed starting height and content as the enhanced example, but its intrinsic end state cannot be interpolated.

  • height: 2.9rem → auto
  • transition: height 700ms

allow-keywords

This is the same pattern, now with interpolate-size: allow-keywords inherited from the demo wrapper.

  • height: 2.9rem → auto
  • transition: height 700ms
.demo {
  interpolate-size: allow-keywords;
  height: 2.9rem;
  transition: height 700ms ease;
}
.demo[open] { height: auto; }

Intrinsic sizing, in plain language

It is a size calculated from the content itself: auto, min-content, max-content, or fit-content.

Checking browser support…

:root {
  interpolate-size: allow-keywords;
}

.panel {
  height: 2.9rem;
  overflow: hidden;
  transition: height var(--duration) ease;
}
.panel.is-open { height: auto; }
