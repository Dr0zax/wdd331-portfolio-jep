Blend Modes in Action

The same color wash creates a different visual mood depending on how it blends with the image beneath it.

Multiply

Multiply

Deepens the shadows and creates a rich, moody tint.

background-blend-mode: multiply;
Screen

Screen

Lightens the image with a soft, luminous color wash.

background-blend-mode: screen;
Difference

Difference

Inverts overlapping colors for a high-energy effect.

background-blend-mode: difference;
