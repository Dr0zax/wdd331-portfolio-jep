The six container query units

Each unit represents one percent of a dimension of the nearest eligible query container.

cqw

Query width

1% of the container’s width.

cqh

Query height

1% of the container’s height.

cqi

Inline size

1% of the container’s inline axis.

cqb

Block size

1% of the container’s block axis.

cqmin

Smaller axis

1% of the smaller container dimension.

cqmax

Larger axis

1% of the larger container dimension.

  1. Declare a container: container-type: size; enables both axes. Use inline-size when you only need the inline axis.
  2. Choose the right unit: use cqi for writing-mode-aware inline sizing, or cqw/cqh when you need physical width and height.
  3. Combine with guardrails: clamp() keeps a value readable even when the component becomes very small or very large.
